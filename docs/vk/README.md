# Qybeq VK Games

Приложение VK Games: `54815710`.

## Сборка

```sh
npm ci
npm run check
npm run build:vk
```

VK-сборка появляется в `dist-vk/`. GitHub Pages публикует её в подпапке
`/vk/`, поэтому адрес игры имеет вид:

```text
https://<домен-pages>/<путь-проекта>/vk/
```

Материалы для вкладки «Оформление» находятся в
`build/releases/vk/design/`. Размеры и контрольные суммы перечислены в
`manifest.json`.

## Монетизация

В коде уже подключены VK Bridge и rewarded native ads:

- проверка доступности — `VKWebAppCheckNativeAds`;
- показ рекламы — `VKWebAppShowNativeAds` с форматом `reward`;
- награда выдаётся только после успешного результата показа;
- рекламный ролик используется в текущем игровом сценарии дополнительных
  подсказок.

В кабинете VK нужно открыть приложение `54815710`, перейти в «Монетизация» и
зарегистрироваться в кабинете выплат. По официальной документации VK переход
и регистрация доступны только создателю игры; выплаты за рекламу и покупки
становятся доступны после прохождения модерации и попадания игры в каталог.

До публикации проверьте реальный показ rewarded-рекламы внутри VK и включите
монетизацию в кабинете. Наличие API-вызовов в сборке само по себе не означает,
что объявление уже будет доступно в тестовом запуске.
